# EMG-EPN612 Dataset

Source: EMG-EPN2020 (Myo Armband hand-gesture dataset). Stored locally under
`resources/data/EPN612/` (git-ignored; reproducibility anchored via a content
hash, not committed bytes).

## Overview

- **612 subjects total**, split into two cohorts of **306 each**:
  - `trainingJSON/` — training cohort.
  - `testingJSON/` — validation/evaluation cohort.
- The two cohorts are **different people** (not the same 306 users re-split).
  Both folders reuse the *same local numbering* (`user1`..`user306`), so subject
  identity must be **cohort-qualified**: `train:userN` vs `test:userN`.

## Per-subject JSON structure

```
{
  "generalInfo": {
    "deviceModel": "Myo Armband",
    "samplingFrequencyInHertz": 200,
    "recordingTimeInSeconds": 5,
    "repetitionsForSynchronizationGesture": 5,
    "myoPredictionLabel": { "noGesture": 0, "fist": 1, "waveIn": 2,
                            "waveOut": 3, "open": 4, "pinch": 5 }
  },
  "userInfo": {
    "name": "user1", "age": 19, "gender": "man", "occupation": "student",
    "ethnicGroup": "latin", "handedness": "right", "ArmDamage": "False",
    "distanceFromElbowToMyoInCm": 6, "distanceFromElbowToUlnaInCm": 24,
    "armPerimeterInCm": 23, "date": "30-Oct-2019 14:34:28"
  },
  "synchronizationGesture": { ... },
  "trainingSamples": { "idx_1": {...}, ..., "idx_150": {...} },
  "testingSamples":  { "idx_1": {...}, ..., "idx_150": {...} }
}
```

- `trainingSamples` and `testingSamples` each hold **150 gesture executions**
  (25 per gesture × 6 gestures), each a ~5 s recording.

## Per-sample fields

| Field | Meaning |
|---|---|
| `startPointforGestureExecution` | int, sample index where the gesture begins |
| `myoDetection` | Myo's onboard detection, ~50 Hz (len ~250) |
| `gestureName` | str, the gesture label |
| `groundTruthIndex` | `[start, end]` tuple of EMG sample indices delimiting the gesture (present on gesture samples in `trainingSamples` only) |
| `emg` | 8 channels (`ch1`..`ch8`), ~992–1000 samples @ 200 Hz |
| `quaternion` / `gyroscope` / `accelerometer` | IMU (len ~250, ~50 Hz) |

**Gestures** (via `myoPredictionLabel`): `noGesture`=0, `fist`=1, `waveIn`=2,
`waveOut`=3, `open`=4, `pinch`=5.

To run a **5-class** (gesture-only) experiment that excludes `noGesture`, set
`dataset.include_no_gesture=false` (optionally with `gesture_crop=none`): the
rest class is removed before windowing, and the model is trained and scored only
on gesture-active windows.

## Labeled / unlabeled structure

| | `trainingJSON/` | `testingJSON/` |
|---|---|---|
| `trainingSamples` | labeled + `groundTruthIndex` | labeled + `groundTruthIndex` |
| `testingSamples` | labeled (no `groundTruthIndex`) | **unlabeled** (no `gestureName`) |

The `testingJSON.testingSamples` block is the competition-style held-out test
set (no labels) and is therefore **not loaded** by the framework.

## Framework split strategy

The `predefined` split maps the dataset as (subject-independent):

- **train / val** = a subject-wise split of the `trainingJSON` cohort (306
  users, both their `trainingSamples` and labeled `testingSamples`).
- **test** = the `testingJSON` cohort (306 users, their labeled
  `trainingSamples`), held out entirely.

Subject ids are cohort-qualified (`train:`/`test:`). This gives a genuinely
independent user-level test: no subject appears in more than one partition
(enforced by `assert_no_group_leakage`).

## User information

Each subject's `userInfo` (age, gender, occupation, ethnic group, handedness,
arm damage, arm measurements, date) is loaded onto the subject's `User` as
`demographics` (a dict keyed by cohort-qualified `user_id`) for later
demographic analysis (e.g. accuracy by gender/handedness).
